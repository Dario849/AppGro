# AppGro Rewrite Workspace

This branch is a full rewrite of AppGro.

## Mission

Build a new agricultural management and analytics web app from scratch, using:
- Frontend: Astro
- Backend: Python + FastAPI
- Documentation: Markdown + Mermaid

## Product Scope (from legacy discovery)

Core domains and modules expected in the rewrite:
- User management and role permissions
- Login and account recovery
- Task management with priorities and scheduling
- Calendar task navigation
- Livestock tracking (caravana, health, weight, diet, events)
- Crop tracking (sowing, treatments, yields, weather impact)
- Financial tracking (purchases, sales, summaries, notes)
- Interactive map with editable sectors/lots
- Tools/equipment tracking and maintenance
- Notifications (in-app)
- Weather integration
