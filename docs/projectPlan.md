## this is a rewriting project for the main branch for this gh repo "AppGro"
* AppGro is a web-app for management and stats analysis of the agricultural sector.
* Original documentation is found inside the `OLD\` directory.
* The new documentation will be found inside the `docs\` directory, and will be built using Mermaid.js for documentation and analysis. 
* The original stack used is PHP + Vite/JavaScript
* The main objective of the rewriting project is to create:
  * A new stack: Astrojs + Python/FastAPI.
  * Be built from "zero," taking the old documentation as reference
## Some of the planned steps include: 
  - Building first new updated documentation, giving all possible specs for this new stack and project.
  - Scaffold the intended stack
  - Prepare backend and DB
  - Build preliminary frontend for testing main functions
  - Improve backend and frontend for requirements compliance
  - Build UI/UX experience
  - QA testing
  - Send to production
## To summarize:
This is a branch for rewriting/migrating to a new stack for AppGro. The main objective is to create a new web-app for management and stats analysis of the agricultural sector, using Astrojs + Python/FastAPI. The project will be built from "zero," taking the old documentation as reference, and using Mermaid.js for new documentation and analysis.
